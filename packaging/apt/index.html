Fleck packages

Sticky notes for the COSMIC desktop. This is the apt repository; the source and the releases are at github.com/joelebukatobi/fleck.

Installing

Add the repository once, and Fleck updates with the rest of your system:

curl -fsSL https://joelebukatobi.github.io/fleck/fleck.gpg \
  | sudo tee /usr/share/keyrings/fleck.gpg > /dev/null
echo 'deb [signed-by=/usr/share/keyrings/fleck.gpg] https://joelebukatobi.github.io/fleck stable main' \
  | sudo tee /etc/apt/sources.list.d/fleck.list
sudo apt update && sudo apt install fleck

Then add the panel applet in COSMIC Settings: Desktop, Panel, Configure panel applets. Dictation needs a speech model, about 142 MB, downloaded once:

mkdir -p ~/.local/share/fleck/models
curl -fL -o ~/.local/share/fleck/models/ggml-base.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin

Removing it

sudo apt remove fleck
sudo rm /etc/apt/sources.list.d/fleck.list /usr/share/keyrings/fleck.gpg
